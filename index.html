POST /api/v1/products/checkout Baixa de Estoque Inteligente (Venda/Descarte)
Motor FIFO Automático

Utilize esta rota toda vez que um produto passar no caixa ou for descartado. Não é necessário enviar a data de validade. O motor inteligente do VOKZO utiliza o método FIFO (First-In, First-Out), buscando o lote ativo daquele código de barras e dando baixa automaticamente na unidade que estiver mais próxima do vencimento.

Headers Obrigatórios (Autenticação):
x-api-key: Sua Chave de API
x-tenant-id: ID da Loja
Body (JSON):

  "codigo_barras": "7891010101010",
  "quantidade_vendida": 2
}
